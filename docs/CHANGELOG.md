# История изменений

## Документация 1.0.0 — NCEA Community License 1.0

- Для текущей ветки введена пользовательская лицензия с разрешением реальных
  форков и запретом выдавать косметически переименованную копию за новый продукт.
- Добавлены русский перевод, краткое руководство и правила использования
  обозначений. Заимствованные материалы сохраняют собственные лицензии.
- Версия программы и опубликованный тег `v1.0.0` не изменены. Новые условия
  действуют с коммита этого изменения и не меняют ранее распространённые копии.

## Документация 1.0.0 — адаптация README из AngelOS

- Структура русского и английского README переделана в 12 записей с использованием адаптированных исходных SVG AngelOS.
- Добавлены атрибуции MIT/OFL, отдельные лицензии, визуальный аудит и три схематических GIF NCEA.
- Исходники античита, JAR и опубликованный тег `v1.0.0` не менялись.

## 1.0.0 Stable — 2026-11-01

- Версия продукта, метаданные Gradle и `plugin.yml`, консоль, команды и документация переведены на 1.0.0 Stable по решению владельца.
- Переработаны визуальные ресурсы README: пиксельный знак из предоставленного изображения, анимированная шапка, отдельные демонстрации пяти проверок, фирменные плашки, схема архитектуры, консоль, конфигурация и документация.
- Подтверждены 77 JUnit-тестов, чистая сборка и отдельные smoke-запуски Paper 1.20 и 1.20.1; подробности в [результатах тестирования](TEST_RESULTS.md).
- Режим OBSERVE, пять проверок и известные ограничения сохранены. Статус Stable относится к выпуску текущего функционала, а не к отсутствию будущих задач.


## 0.1.0 Development — GitHub-публикация

- Созданы оригинальные SVG-шапка, разделитель, схемы, консольный предпросмотр, статус и футер на базе предоставленного пиксельного NCEA AC.
- Добавлен короткий GIF предпросмотра логотипа без игровых кадров и воспроизводимый скрипт генерации.
- Переработаны русская и английская страницы README; добавлены ссылки на документацию, фактические проверки и ограничения.
- Добавлен GitHub Actions workflow для Java 17, JUnit и двух Paper-артефактов.
- Обнаружено и сохранено оригинальное изображение `Ascii/Ascii final result.png`; исправлены прежние утверждения о его отсутствии.


## 0.1.0 Development — доработки качества, 2026-11-01

- Добавлен ASCII-баннер с режимами `3d`, `classic`, `compact`, `disabled` и управляемыми полями.
- Добавлена миграция недостающих параметров баннера с резервной копией старого `config.yml`.
- Исправлена длительность окна Speed, объединение вертикального движения Fly и повторные события позиции и разрывы координат.
- Отключённые проверки больше не обновляют своё состояние; уведомления ограничены по проверке.
- Добавлены типизированная валидация чисел, проверка нечисловых значений и тесты reload.
- Добавлены JaCoCo, расширенные unit-тесты и повторная проверка двух Paper-серверов.
- Выпущен комплект русской и английской документации.

## 0.1.0 Development — исходная рабочая сборка

Пять наблюдательных проверок, отдельный VL/decay, административные команды и отдельная компиляция под Paper 1.20/1.20.1. Прежние [результаты](TEST_RESULTS.md) сохранены в истории документа.

## 0.1.0 Development — консольное оформление и QA

- Оригинальная семистрочная геометрия перенесена из предоставленного Bash-источника в UTF-8 сегменты; исходные файлы не исполняются и сохранены.
- Добавлены темы, ANSI 16/256/TrueColor, безопасный автоматический режим, ASCII/монохромный/компактный fallback, HTML и текстовый предпросмотр.
- Добавлены `branding.yml`, безопасный пользовательский шаблон, миграция старых настроек, валидация и перезагрузка.
- Добавлены тесты снимка логотипа, рендерера и загрузчика; результаты этой доработки приведены отдельно в [TEST_RESULTS](TEST_RESULTS.md).
