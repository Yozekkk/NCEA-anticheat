The original source files were not edited. NCEA's own [LICENSE](../LICENSE) remains separate; it does **not** relicense these MIT assets.

## Embedded fonts

The adapted SVGs contain freshly subsetted WOFF2 fonts from the inspected upstream tree so new NCEA text renders without system-font substitution:

| Font | Upstream path | License and retained notice |
|---|---|---|
| CozetteVectorBold | `.local/share/fonts/pixel/CozetteVectorBold.ttf` | MIT © 2020 Ines; [notice](licenses/COZETTE-MIT.txt) |
| Pixeloid Sans Bold | `.local/share/fonts/pixel/PixeloidSans-Bold.ttf` | SIL OFL 1.1 © 2020–2022 GGBotNet; [notice](licenses/ANGELOS-FONTS-OFL-1.1.txt) |
| Caveat | `.config/quickshell/angelos/data/fonts/Caveat-Variable.ttf` | SIL OFL 1.1 © 2014 The Caveat Project Authors; [notice](licenses/ANGELOS-FONTS-OFL-1.1.txt) |

The embedded subsets remain under their original font licenses. No other upstream fonts, icons, wallpapers, screenshots or demo GIFs were copied. The `docs/demo/` GIFs were studied for pacing and placement only. The three new GIFs in `assets/angelos-adapted/demos/` are NCEA schematic visualizations generated by [`scripts/generate_angelos_readme_demos.py`](../scripts/generate_angelos_readme_demos.py), not AngelOS interface footage. The older NCEA GIFs reused in the README are also schematic and remain locally generated.

## Reproduction

Clone the pinned revision outside this repository, inspect its licenses, then run:

```bash
python3 scripts/adapt_angelos_readme.py /tmp/ncea-angelos-reference
python3 scripts/generate_angelos_readme_demos.py /tmp/ncea-angelos-reference
```

The scripts require `fontTools` with WOFF2 support, Pillow, and the verified upstream font files. They do not run upstream scripts.
