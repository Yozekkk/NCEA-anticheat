# Устранение проблем

| Симптом | Проверка | Действие |
|---|---|---|
| Плагин отключается при старте | Лог `Unsupported Paper version` | Используйте Paper 1.20/1.20.1 и подходящий JAR |
| Баннер не показан | `console.banner.enabled/style`, ошибка инициализации | Проверьте `config.yml`, лог `Invalid configuration`, `/nceaac config validate` после исправления |
| Старый конфиг изменился | `config.yml.bak-<timestamp>` | Дополнительные ключи баннера добавляются с резервной копией |
| `/nceaac` сообщает об отсутствии прав | `nceaac.admin` или `nceaac.alerts` | Выдайте нужное право в системе прав |
| Нет уведомлений | Право, `/nceaac alerts`, порог VL | Включите уведомления для своей сессии, проверьте `checks.yml` |
| Проверка не срабатывает | `/nceaac checks`, ping/TPS, режим и контекст игрока | Проверьте исключения и ограничения в [CHECKS.md](CHECKS.md) |
| `reload` отклонён | `/nceaac config validate` | Исправьте тип/диапазон YAML; прежняя конфигурация остаётся активной |
| Ошибка Gradle `JAVA_COMPILER` | `JAVA_HOME` указывает на JRE | Укажите путь к полному JDK 17+ |

Если проблема воспроизводится, сохраните версию Paper, Java, JAR SHA-256, соответствующий фрагмент лога и шаги воспроизведения. Не публикуйте личные данные игроков из логов.
