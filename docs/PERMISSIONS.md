# Права доступа

| Permission | По умолчанию | Действие |
|---|---|---|
| `nceaac.admin` | OP | Административные команды и tab completion |
| `nceaac.alerts` | OP | `/nceaac alerts` и получение уведомлений после включения |
| `nceaac.bypass` | false | Полное исключение игрока из проверок |

Права объявлены в `plugin.yml`. Временная команда `/nceaac exempt` хранит UUID только до выхода игрока или отключения плагина. Уведомления выключены для новой сессии до ручного включения.
