# Команды

Все команды используют `/nceaac`. Кроме `alerts`, требуется `nceaac.admin` (по умолчанию OP). `alerts` доступна также владельцу `nceaac.alerts`.

| Подкоманда | Действие |
|---|---|
| `help` | Краткая справка |
| `status` | Версия, число сессий и версия Paper |
| `version` | Тот же статус версии |
| `checks` | Пять ID и включённость |
| `alerts` | Включить/выключить получение уведомлений в текущей сессии; только игрок |
| `violations <player>` | VL и последнее доказательство игрока онлайн |
| `profile <player>` | Сейчас эквивалент `violations` |
| `debug <player>` | Сейчас эквивалент `violations` |
| `reset <player>` | Очистить VL, таймеры уведомлений и временное состояние проверок |
| `exempt <player>` / `unexempt <player>` | Временное исключение игрока онлайн / его отмена |
| `performance` | Число вызовов и среднее время `inspect` по категориям событий |
| `reload` | Проверить и загрузить `config.yml`, `checks.yml` без перезапуска |
| `config validate` | Последний результат валидации |

Табуляция дополняет подкоманды и имена игроков онлайн. Offline-профили и отдельный `verbose` режим не реализованы. `profile` и `debug` не притворяются отдельными аналитическими интерфейсами.
