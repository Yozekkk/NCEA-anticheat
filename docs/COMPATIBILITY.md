# Совместимость

| Сервер | API при компиляции | Java bytecode | Проверка запуска | Игровое тестирование |
|---|---|---|---|---|
| Paper 1.20 | `1.20-R0.1-SNAPSHOT` | 17 (major 61) | Локальный Paper build 17 | Не проведено |
| Paper 1.20.1 | `1.20.1-R0.1-SNAPSHOT` | 17 (major 61) | Локальный Paper build 196 | Не проведено |
| Другие версии | Не поддерживаются | — | Плагин отключается | Не проводилось |

Оба JAR компилируются отдельными задачами. Сейчас их байткод совпадает, поскольку версия API не требует разного исходного адаптера; это документируется и проверяется по хешам. `plugin.yml` задаёт `api-version: '1.20'`. NMS отсутствует. Старые конфигурации схемы 1 автоматически получают параметры баннера с резервной копией.

На рабочей машине Java 17 доступна для серверного запуска, а компилятор — в JDK 25. Используйте полный JDK для Gradle и `--release 17`; JRE без `javac` недостаточна. Успешная загрузка сервера и команд не доказывает работу детекторов в реальном PvP. См. [результаты](TEST_RESULTS.md).
